# BARA 도형심리 역량진단 웹서비스 요구사항서
Version: 1.0  
Target: `bara-edu.kr` 기존 사이트 내부 통합  
Primary route: `/diagnosis` 또는 `/shape-check`  
Project type: 기존 사이트 기능 추가  
Important: **PBA Radar와 완전히 별개의 시스템으로 개발한다.**

---

## 0. Claude 작업 지시

이 문서는 `bara-edu.kr`에 추가할 **도형심리 과정 적합도/역량진단 기능**의 구현 요구사항이다.

### 반드시 먼저 할 일
1. 현재 `bara-edu.kr` 코드베이스의 프레임워크, 라우팅, 스타일 시스템, 배포 방식을 먼저 분석한다.
2. 기존 UI/UX를 최대한 유지한다.
3. 기존 로그인/회원/결제/과정 상세 기능이 있다면 새로 만들지 말고 재사용한다.
4. 기존 기능을 깨뜨리지 않는 방식으로 구현한다.
5. PBA Radar 관련 코드, 문항, 데이터, 브랜드를 절대 혼합하지 않는다.

### 구현 원칙
- 모바일 우선 반응형
- 진단 완료까지 5분 이내
- 결과의 핵심 목적은 "현재 실력 증명"이 아니라 **적합한 학습 과정 추천**
- 자기평가 결과만으로 자격 취득/강사 자격을 자동 판정하지 않는다.
- 심리적·의학적 상태를 진단하는 서비스처럼 표현하지 않는다.
- 결과 페이지에서 가장 중요한 CTA는 **추천 과정 상세 보기 / 수강 신청 / 문의**

# 1. 서비스 목적

도형심리를 처음 접한 사람부터 과거 학습 경험자, 기존 자격 보유자까지 현재의 학습·활용 수준을 스스로 점검하고 다음에 어떤 과정을 수강하는 것이 적합한지 안내한다.

## 주요 목적
1. 2급 / 1급 / 향후 강사과정 중 적합한 시작점을 안내
2. 과거에 배웠지만 활용하지 못하는 학습자의 재진입 유도
3. 사용자의 강점/보완 영역 시각화
4. 과정 상세 페이지 및 수강 신청으로 자연스럽게 연결
5. 교육 상담 시 활용 가능한 진단 데이터 축적

## 비목표
- 임상 심리진단
- 정신건강 상태 판정
- 자격증 자동 부여
- 강사 자격 자동 확정

# 2. 핵심 사용자

## Persona A — 입문자
- 도형심리를 처음 접함
- 자신에게 맞는 과정이 2급인지 궁금함

## Persona B — 과거 학습자
- 예전에 도형심리를 배웠으나 기억이 흐릿함
- 실제 활용 경험이 적음
- 자격증이 없거나 재교육 필요

## Persona C — 기존 자격 보유자
- 기본 이론은 알고 있음
- 상담/코칭/사례분석에서 어려움을 느낌
- 1급 또는 실습/슈퍼비전이 적합할 수 있음

## Persona D — 강사 후보자
- 실무 경험과 기본 역량이 높음
- 교육 및 지도 역량 점검 필요
- 강사과정 지원 적합성의 "사전 확인" 목적

필수 요소:
- 제목: `도형심리 역량진단`
- 보조 문구: `나에게 맞는 과정은 어디부터일까요?`

최소 수집 원칙.

권장 필드:
- 이름 또는 닉네임
- 이메일 또는 휴대전화: 결과 저장/상담 연결 시 선택 또는 필수 여부 정책 결정
- 도형심리 학습 경험
  - 처음
  - 과거 수강 경험 있음
  - 자격증 있음
  - 현재 활용 중
- 보유 자격 수준(선택)

개인정보 수집 시 기존 BARA 개인정보처리방침과 동의 UI를 재사용한다.

## 4.3 진단 문항
- 1페이지당 5문항 또는 영역별 페이지 구성
- 상단 진행률 표시
- 이전/다음 가능
- 답변 누락 시 다음 진행 방지
- 모바일에서 큰 터치 영역 확보

## 4.4 결과 페이지
표시 순서:
1. 추천 과정

4. 강점 1~2개

6. 왜 이 과정을 추천하는지 설명
7. 다음 단계 CTA
8. 주의 문구

# 5. 응답 척도

모든 문항은 0~4점.

| 점수 | 의미 |
|---|---|
| 0 | 처음 접한다 / 거의 알지 못한다 |
| 1 | 들어본 적 있다 |
| 2 | 설명할 수 있다 |
| 3 | 실제로 적용할 수 있다 |
| 4 | 다른 사람을 지도할 수 있다 |

사용자에게 점수 숫자보다 문구를 먼저 보여준다.

# 6. 진단 영역

총 6개 영역 × 5문항 = 30문항.

1. 기본 이론 이해
2. 도형 판독 능력
3. 분석 능력
4. 상담·활용 능력
5. 사례 분석·기록 능력
6. 교육·지도 능력

각 영역 원점수 최대 20점.
결과 화면에서는 0~100점으로 환산.

```text
영역점수(100점) = (영역 원점수 / 20) × 100
전체점수(100점) = 6개 영역 점수 평균
```

# 7. 문항 정의

## A. 기본 이론 이해
A1. 도형심리 검사의 목적과 기본 원리를 설명할 수 있다.  
A2. 동그라미·세모·네모·에스의 기본적인 기질적 특징을 구분할 수 있다.  
A3. 각 도형의 강점과 보완점을 설명할 수 있다.  
A4. 기질과 성격을 구분하여 설명할 수 있다.  
A5. 도형심리 검사의 진행 순서와 기본적인 검사 방법을 알고 있다.

## B. 도형 판독 능력
B1. 검사지에서 1차·2차·3차·4차 도형을 구분할 수 있다.  
B2. 주도형에서 나타나는 여러 형태를 구별하고 기본 의미를 설명할 수 있다.  
B3. 복합도형과 복합기질을 구분하여 해석할 수 있다.  
B4. 이분법 도형과 보조도형을 찾아낼 수 있다.  
B5. 도형의 크기·위치·겹침·반복 등 그림에서 나타나는 특징을 관찰할 수 있다.

## C. 분석 능력
C1. 한 개의 특징만 보는 것이 아니라 여러 도형 정보를 종합해 해석할 수 있다.  
C2. 상·중·하 등 주요 분석 기준을 실제 검사지에 적용할 수 있다.  
C3. 라이프쇼크·조인트포인트 등 주요 분석기법을 찾아보고 해석 근거를 설명할 수 있다.  
C4. 검사지의 특이 특징을 단정적으로 판단하지 않고 다른 정보와 함께 확인할 수 있다.  
C5. 처음 보는 검사지도 일정한 분석 순서에 따라 전체적으로 분석할 수 있다.

## D. 상담·활용 능력
D1. 검사 결과를 상대방이 이해하기 쉬운 언어로 설명할 수 있다.  
D2. 결과를 일방적으로 설명하기보다 질문을 통해 검사자의 실제 경험과 연결할 수 있다.  
D3. 도형의 특징을 관계·커뮤니케이션·강점 등의 실제 생활 문제에 연결할 수 있다.  
D4. 검사 결과와 실제 상담 내용이 다를 때 추가적인 정보를 확인할 수 있다.  
D5. 도형심리 분석과 임상적 진단을 구분하고 필요한 경우 전문기관 안내가 필요한 상황을 판단할 수 있다.

## E. 사례 분석·기록 능력
E1. 검사 내용을 정해진 분석 양식에 따라 기록할 수 있다.  
E2. 내가 내린 해석의 근거를 다른 사람에게 설명할 수 있다.  
E3. 상담 내용을 축어록 또는 사례기록 형태로 정리할 수 있다.  
E4. 이전 검사와 현재 검사를 비교해 변화나 차이를 관찰할 수 있다.  
E5. 내 분석에 확신이 없을 때 슈퍼비전이나 다른 전문가의 의견을 활용할 수 있다.

## F. 교육·지도 능력
F1. 도형심리를 처음 배우는 사람에게 4가지 도형을 쉽게 설명할 수 있다.  
F2. 학습자가 잘못 분석한 부분을 발견하고 이유를 설명할 수 있다.  
F3. 하나의 사례를 가지고 분석 과정을 단계적으로 시연할 수 있다.  
F4. 도형심리 실습이나 그룹 교육을 진행할 수 있다.  
F5. 교육 중 질문이나 예외 사례가 나왔을 때 근거를 가지고 답변할 수 있다.

# 8. 과정 추천 로직

> 주의: 아래는 "학습과정 추천" 로직이며 자격 인증 로직이 아니다.

## 8.1 2급 추천
아래 중 하나 이상:
- 기본이론 < 60
- 도형판독 < 60
- 전체평균 < 60
- 학습 경험이 없거나 오래되어 기초 재정리가 필요함

추천 라벨:
`기초부터 체계적으로 정리하는 단계`

## 8.2 1급 추천
권장 조건:
- 기본이론 >= 65
- 도형판독 >= 65
- 분석능력 >= 60
- 그리고 상담활용 또는 사례기록 < 70

추천 라벨:
`기본 분석에서 실전 활용로 확장하는 단계`

## 8.3 1급 실습/슈퍼비전 집중 추천
권장 조건:
- 기본이론 >= 75
- 도형판독 >= 75
- 분석능력 >= 70
- 상담활용 < 75 또는 사례기록 < 75

추천 라벨:
`새로운 이론보다 사례와 피드백이 필요한 단계`

## 8.4 강사과정 사전 적합 후보
모두 충족 권장:
- 기본이론 >= 80
- 도형판독 >= 80
- 분석능력 >= 80
- 상담활용 >= 75
- 사례기록 >= 75
- 교육지도 >= 75
- 전체평균 >= 80

표현:
`강사과정 사전 적합 후보`

반드시 추가:
`자가진단 점수만으로 강사 자격을 판정하지 않습니다. 실제 사례 분석, 과정 이수, 시범강의 및 별도 평가가 필요합니다.`

## 8.5 경계값 처리
여러 추천 조건이 겹칠 경우:
1. 기본 역량 결손이 있으면 하위 과정 우선
2. 기초가 충분하면 실전/심화 추천
3. 강사후보는 모든 최소 기준 충족 시에만 노출

# 10. 자동 해석 규칙

## 강점
6개 영역 중 최고점 1~2개.

예시:
- 기본이론: `기초 개념을 비교적 안정적으로 이해하고 있습니다.`
- 분석능력: `여러 정보를 종합해 해석하는 능력이 강점입니다.`

## 보완 영역
최저점 1~2개.

예시:
- 상담활용: `지식을 실제 상담 언어로 바꾸는 연습이 더 필요합니다.`
- 사례기록: `분석 근거를 기록하고 검토하는 경험을 보완하면 좋습니다.`

해석 문구는 DB/config로 관리하여 코드 수정 없이 변경 가능하게 한다.
